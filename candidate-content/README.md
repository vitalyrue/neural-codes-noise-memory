# Candidate content

Keep proposed text, transitions, evidence selections, visual prompts, editable
visual sources, image candidates, and review atlases here while they are being
considered. Nothing in this directory is published automatically.

Promote accepted prose to `content/`, accepted images and editable sources to
`assets/approved/`, and accepted mappings to `source-maps/`. Large rejected or
historical candidate collections should move to external archive storage rather
than making the normal book repository grow without limit.
