# Draft diagram generation status

Forty-six candidate files were generated for the four Parts, 22 numbered chapters and three front-matter units; the generation manifest identifies each prompt and intended file. Longer chapters use pairs. These are unapproved drafts and were not inserted into the guide.

Known problems from limited observation: ch07-draft-v1.png shows the common-variance estimate as 0.82 ± 0.08, whereas the guide reports 0.82 ± 0.07; the image needs source checking and correction. Some Part III/IV drafts include scenes without labels identifying their mechanisms. Some prompts specified only a few principal labels, which does not ensure that each meaningful scene is understandable. Other generated figures may have missing labels, unsupported arrows, inaccurate formulas or poor readability. The requested extended figure review was not performed, so this is not a complete defect list.

Each prompt and source brief is recorded in generation-manifest.json and the prompts-a, prompts-b, and prompts-c folders. Original generated files remain in the user's generated_images directory, and draft copies are in the book candidate folder. Style lock consistency was checked for the briefs; that does not establish image palette or content correctness. Existing figures and guide text were not modified.

A three-image spot check of ch14-a, ch17-a and ch19-a found that the three principal labels requested by each prompt were present, but multiple other scenes and axes lacked labels. In these examples the prompt itself underspecified the labels; no claim is made about all 46 images.
