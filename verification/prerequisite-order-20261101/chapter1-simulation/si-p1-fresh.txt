                      I.  STOCHASTIC DYNAMICS IN THE LARGE N LIMIT


  To formally derive the dynamic equations in the large N limit, we consider a network with

M sub-populations, each containing n neurons, so that the total number of neurons is N = nM.

Within each sub-population, all neurons share the same incoming and outgoing weights, as well as

the same bias. We scale the weights with n such that the total synaptic input to a neuron in each

population is independent of n:
