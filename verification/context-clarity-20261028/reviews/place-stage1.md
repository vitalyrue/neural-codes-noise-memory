## Findings

### P1. Pair physical dimensions with the animal's movement before using room versus track comparisons

- Location: 05-place-fields.md opening, line 3; repeated purpose in 05-place-fields.yaml. Connected dependent use: 05b-place-sizes.md opening and PLACE-SIZE-LAW.
- Original: "A cell recorded on a short track may have one smooth firing hill. On a long track, the same kind of cell may have several separated fields, each with a different width and height. In a room, its active regions can bend, split, and surround inactive holes."
- Missing context: The earlier reading guide identifies rodents/bats and one/two/three dimensions, but does not pair dimensions with movement. The text later makes track/arena/room correspond to 1D/2D/3D. A reader without neuroscience can reasonably picture an animal walking on a room floor, which gives two spatial coordinates, and miss why a room contributes volumes. Also, a tunnel has physical width and height, so its reduction to one coordinate needs the movement constraint, rather than the everyday noun alone.
- Proposed repair: Add a compact setup before or within this opening: "The recordings include bats flying along nearly one-dimensional tunnel routes, rats moving across a two-dimensional arena floor, and bats flying through a room in three dimensions. The dimensions describe the animal's available movement coordinates." Keep the existing observation/problem prose and the detailed experiment table later. If shorter wording is preferred, state that the tunnel analysis uses distance along the route, whereas the room analysis uses all three position coordinates. Do not suggest that all datasets share one task or newly collected protocol.
- Source evidence: mainali-2025-full-text-layout.txt lines 153-157 describes the stereotyped bat trajectory along the 1D track; lines 198-200 describes rats in 2D and bats in 3D; Figure 2A/F, lines 362 and 429, pairs the rat arena with the bat flight room; Figure 4A, lines 543-544, explicitly pairs dimensions and animals. mainali-2025-text-columns.txt PDF pages 3, 5-6, 8 provide the same setting.
- Later explanation: 05c-place-tests.yaml table PLACE-DATA-COMPARISONS supplies species and room size only after both earlier place chapters. 06-synthesis RELATED says "three-dimensional bat recordings." These are useful records, but too late for the first dimensional comparison. 05-place-fields line 48 correctly defines length/area/volume but does not explain why these are the measured movement dimensions.
- Verdict: Context gap, not a false mathematical claim. One early setup is sufficient; no repeated species/task descriptions are needed beside every result.

### P2. Give the biological meaning of the model's spatial input at its first use

- Location: 05-place-fields.md opening, line 5, connected to PLACE-GP's h(x), z(x), and threshold rule. The figure caption PLACE-GP-TO-FIRING also uses "Gaussian input" after this introduction.
- Original: "Mainali, Azeredo da Silveira, and Burak propose that a cell's spatial input is a smooth random function. The cell fires where this function exceeds a threshold."
- Missing context: Earlier foundations explains synaptic input and rate maps, but this passage never connects the particular function h(x) to what reaches the cell. The reader must infer whether "spatial input" means position supplied numerically, a firing-rate map, or incoming synaptic drive. That distinction matters because h can be negative and Gaussian, while the output firing rate is nonnegative and generally not Gaussian. The model's mathematical definition is clear; its biological object is left implicit.
- Proposed repair: Add beside first use: "This function can be interpreted as the average combined input arriving through the cell's synapses at each animal position. The recorded rate map describes the cell's output; the model applies a threshold to this hidden input to predict that output." Keep "can be interpreted" because the paper does not directly measure this input or establish the particular circuit mechanism. Then retain the existing normalized h/z/F equations. A shorter sufficient repair may combine the second sentence with the existing threshold sentence, preserving this distinction.
- Source evidence: place-supplement.txt Methods S1 lines 460-468 explicitly identifies x as animal location and the Gaussian process as a possible description of mean synaptic input from spatially tuned presynaptic partners, with threshold-linear conversion to firing rate. Main article Figure 1B, full-text-layout.txt lines 271-272, gives summed incoming signals followed by rectification; main text lines 161-163 identifies CA3 and entorhinal contributions.
- Earlier explanation checked: 01-foundations.md lines 11-16 explains input effects; lines 28-35 explains recorded spatial maps and CA3/CA1 input. These establish the ingredients but do not identify this new h(x) as their modeled combination.
- Later explanation: 05c-place-tests.md line 121 explicitly distinguishes measured rate maps from hidden Gaussian input; PLACE-WIRING lines 157-165 models a sum of spatially tuned input neurons; line 198 says relevant weights and subthreshold inputs were not measured. This confirms the intended interpretation but is two chapters after h is first used.
- Verdict: Missing local biological link. The random-weight mechanism should stay in PLACE-WIRING; only the meaning of the input belongs here.
